# php-7.3 phase

The second modernization phase: the step from PHP 7.2 to PHP 7.3, and nothing else. The
project plan, branch model and the rules every phase follows are in
[../README.md](../README.md). The work plan, decisions and traps are in
[HANDOFF.md](HANDOFF.md).

## Status: in progress (started 2026-11-20)

- **Environment:** moved to PHP 7.3.33 (MOD-189). The exact image, tools and extension pins are in
  [notes/ENVIRONMENT.md](notes/ENVIRONMENT.md).
- **Tests:** 1,429 tests pass on PHP 7.3.33 (the 1,428 of php-7.2 plus the version test), with
  100% class, method and line coverage (331 classes, 1,062 methods, 8,047 lines).
  How to run them: [../TESTING.md](../TESTING.md).
- **Runtime fixes so far:** one, in the vendored JShrink minifier (MOD-190).
- **Open owner questions:** Q37 and Q38, in [active/KNOWN-DEFECTS.md](active/KNOWN-DEFECTS.md).
  Q38 (two tests switch off the AWS SDK's PHP deprecation notice) must be answered before the
  phase can be declared complete.
- **Not done yet:** the 7.2-to-7.3 migration-guide scan beyond what the tests reach, the
  modernizations (HANDOFF section 3a), the API comparison, the mutation sample, the consumer
  check, the dependency audit, the flat-webapp move to 7.3, the release notes.

## Resume here

1. Read the phase rules in [../README.md](../README.md) and `AGENTS.md`, then
   [HANDOFF.md](HANDOFF.md).
2. Run `docker/bin/test` and confirm 1,429 tests pass before changing anything.
3. Pick up the "Not done yet" list above. Every notice, warning or deprecation is fixed at its
   cause (prime directive 2). Commit runtime fixes, behavior changes and modernizations
   separately, each with its change-log entry.
4. After tests change, regenerate the inventory:
   `tmp=$(mktemp) && docker/bin/test inventory docs/modernization/php-7.3/active/KNOWN-DEFECTS.md > "$tmp" && mv "$tmp" docs/modernization/php-7.3/TEST-INVENTORY.md`
5. Run `docker/bin/check-docs` after every documentation change.
