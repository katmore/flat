# Database, assets, and minifier coverage

## Native PDO checks

`tests/Unit/Db/Pdo/{PdoTest,ConnectionTest,StatementTest}.php` uses the native SQLite
PDO driver in Docker PHP 7.2.34. Connections/databases are in memory; SQL files
and permission fixtures are temporary. Connection-cache state is saved/restored.
The recording subclass delegates preparation to native PDO and retains the actual
statement so tests can execute and inspect the SQL generated by the builder.

Tests cover binding and aliases, execute controls, SQL files and invalid paths,
record arrays/classes/clones/generic objects, callbacks, empty results, caching,
forced connections, connection-provider interfaces, invalid DSNs, and builder
criteria/joins/order/limits/invalid options. This is not MySQL, Mongo, RabbitMQ,
or flat-webapp functional coverage.

A real SQLite regression demonstrated that prepare_map discarded valid SELECT
rows because PDOStatement::rowCount() returned zero. Fetching now determines
whether rows exist. Callback and record mapping semantics are retained. Native
PHP 7.2 SQLite returns integer columns as strings here; tests assert those actual
types rather than coercing them into assumed newer-runtime behavior.

Builder fetch options are still characterized as failing pending owner input;
it unconditionally throws even after accepting valid options. Its independent
rowCount gate also produces not_found for real SQLite SELECT rows. The final
builder fetch loop references undefined data_class. These are not fixed by the
prepare_map repair. load_statement's rules-object branch is blocked by its array
parameter type, while its multi-argument handling uses an unusual keyed layout.

## Assets

`tests/Unit/Asset/{AssetTest,CascadeTest}.php` uses temporary local files and saves
and restores registration/handler state. It covers URL/resource normalization,
hashes, type inference, script/style/file/data URI output, permission failures,
filters/positions, dependency ordering/deduplication, class cascading, built-in
first-instantiation dependencies, callbacks, and legacy aliases. The core asset
controller reaches **36/36 lines, 11/11 methods (100%)**.

Known failures are clearly labeled rather than silently repaired: special HTML
arrays retain the first callback and accidentally add a self dependency. The
fixture inspects this queue without executing infinite recursion; intended
multiple-output behavior is awaiting the owner. Newly constructed inline script
assets have no parent resource value, so file-path-dependent methods raise
TypeError. Bundle enumeration is currently a stub. The directory flag shares
EXISTS bits with FILE and is intercepted by the FILE check; follow-up needed.

## JavaScript minifier

`tests/Unit/Vendor/JsMinifierTest.php` runs the bundled PHP minifier against
whitespace, comments, licenses, conditional comments, quoted/escaped strings,
line continuations, regexes, division, and adjacent increment/decrement tokens.
Malformed comments/strings/regexes must throw, restore output-buffer depth, and
allow subsequent valid minification. No JavaScript runtime execution is claimed.
Current conditional one-line comments lose their newline; this is a deferred
correctness concern even though that path is covered. No vendor version changed.

## Additional native paths (MOD-067, MOD-076, MOD-078–079)

Mongo interface-owned collection names reject manual changes with the documented
illegal exception. A native document-validator error verifies the non-duplicate
insert rethrow. Real SQLite verifies configured SQL-file roots, driver-option
argument overloads and bare record/result flags. The impossible rules-object
branch behind an array parameter is preserved in a disabled comment; builder
fetch behavior remains an unanswered question. JavaScript regex literals with
both quote styles are now covered by the actual minifier.


Asset continuation (MOD-094): composite FILE/DIR flags must match their full masks, because both include EXISTS. Actual directory and permission tests now exercise that distinction. Overridden public path providers test output guards; an explicit path-scoped namespaced read double covers false from file_get_contents without bypassing the native positive paths. Special-output self-cycles remain deferred.


PDO continuation (MOD-102): an explicit test-only buffered PDOStatement adapter counts native SQLite results and supplies those same rows to fetch. This covers the working fetch_callback path and the undefined-data-class error below the row-count gate without claiming native SQLite SELECT row counts. Local closures for fetch options cannot escape their unconditional throw and are retained in conservative comments. Asset missing-position fallback is similarly retained with proof that both private writers always register a validated position.


Owner-approved Mongo continuation (MOD-106): connect=true now pings new eager clients and retries failures. connect=false stays lazy and has no verified timestamp. Existing 60-second TTL governs verified-cache reuse; stale/missing metadata causes a real ping, with failed clients evicted before retries. A test-only local TCP proxy forwards genuine MongoDB protocol traffic and closes sockets to exercise cached failure without invented SDK responses. The framework no longer relies on adapter getConnections metadata.
